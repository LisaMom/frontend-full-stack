ស្តីអំពីការបង់ថ្លៃសិក្សា អាហារូបករណ៍ ៥០%
វគ្គ FullStack Web Development ជំនាន់ទី៣
ឆ្នាំសិក្សា ២០២៥ - ២០២៦

វិទ្យាស្ថាន សាយអិនស៍ អេន ថេកណឡជី អ៊ែតវ៉ានស៍ ឌីវេឡុបម៉ិន (ISTAD) សូមប្រគេន និងជម្រាបជូនដំណឹងដល់សមណនិស្សិត និស្សិតទាំងអស់ ដែលជាបេក្ខជនជ័យលាភីអាហារូបករណ៍ ៥០% វគ្គ FullStack Web Development ជំនាន់ទី៣ អំពីថ្លៃសិក្សាដែលត្រូវបង់ក្រោយទទួលបានអាហារូបករណ៍ ដូចខាងក្រោម៖

I.   សម្រាប់និស្សិតដែលកំពុងសិក្សាថ្នាក់បរិញ្ញាបត្រ នៅ វិទ្យាស្ថាន ISTAD
❖ ថ្លៃសិក្សាក្រោយទទួលបានអាហារូបករណ៍ ២៥០ ដុល្លារ

II.   សម្រាប់អតីតនិស្សិត Foundation Course
❖ ថ្លៃសិក្សាក្រោយទទួលបានអាហារូបករណ៍ ៤០០ ដុល្លារ
❖ ករណីនិស្សិតបង់ថ្លៃសិក្សាទាំងអស់ ក្នុងកំឡុងពេល ១០ថ្ងៃដំបូងបន្ទាប់ពីថ្ងៃជូនដំណឹងនេះ៖ គឺ ៣៥០ ដុល្លារ (ថ្ងៃទី០៣ សីហា ដល់ថ្ងៃទី ១៣ សីហា ២០២៦)។

III.   សម្រាប់និស្សិតទូទៅ
❖ ថ្លៃសិក្សាក្រោយទទួលបានអាហារូបករណ៍ ៥០០ ដុល្លារ
❖ ករណីនិស្សិតបង់ថ្លៃសិក្សាទាំងអស់ ក្នុងកំឡុងពេល ១០ថ្ងៃដំបូងបន្ទាប់ពីថ្ងៃជូនដំណឹងនេះ៖ គឺ ៤០០ ដុល្លារ (ថ្ងៃទី០៣ សីហា ដល់ថ្ងៃទី ១៣ សីហា ២០២៦)។

IV.   សម្រាប់និស្សិតទាំងអស់
❖ និស្សិតទាំងអស់សូមបង់ថ្លៃសិក្សាឱ្យបានមុន ថ្ងៃចន្ទ ទី១៧ ខែ សីហា ឆ្នាំ ២០២៦។
ថ្ងៃចន្ទ ៥រោច ខែទុតិយាសាឍ ឆ្នាំមមី អដ្ឋស័ក ពស ២៥៧០
រាជធានីភ្នំពេញ ថ្ងៃ៣ ខែសីហា ឆ្នាំ២០២៦
